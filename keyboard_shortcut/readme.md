# Linux Keyboard Shortcut Cheat■Sheet
## Window & Workspace Management
- **Alt + Tab** — Switch between windows
- **Alt + Shift + Tab** — Switch backward
- **Super (Windows key) + Arrow Keys** — Snap windows (varies by desktop environment)
- **Super + Tab** — Switch between applications (GNOME)
- **Ctrl + Alt + Arrow (Left/Right)** — Change workspace
- **Ctrl + Alt + Shift + Arrow** — Move window to another workspace
## Terminal Productivity
- **Ctrl + Shift + T** — Open new terminal tab
- **Ctrl + Shift + W** — Close terminal tab
- **Ctrl + L** — Clear screen
- **Ctrl + C** — Kill current command
- **Ctrl + D** — Logout/close terminal
- **Ctrl + R** — Reverse search command history
- **Ctrl + A** — Move to beginning of line
- **Ctrl + E** — Move to end of line
- **Ctrl + U** — Cut entire line
- **Ctrl + K** — Cut until end of line
- **Ctrl + Y** — Paste previously cut text
## File & System Shortcuts
- **Super + E** — File manager (varies by distro)
- **Alt + F2** — Run command prompt
- **Ctrl + Alt + L** — Lock screen
- **PrintScreen** — Screenshot
- **Shift + PrintScreen** — Selective screenshot
## Browser Shortcuts (Linux)
- **Ctrl + T** — New tab
- **Ctrl + W** — Close tab
- **Ctrl + Shift + T** — Reopen closed tab
- **Ctrl + Tab** — Next tab
- **Ctrl + Number (1–9)** — Go to tab
## Text Editing & Cursor Movement
- **Ctrl + Left/Right** — Move one word
- **Ctrl + Shift + Left/Right** — Select words
- **Ctrl + Backspace** — Delete previous word
- **Home/End** — Start/end of line
- **Ctrl + Home/End** — Start/end of document
## System Tools
- **Ctrl + Alt + T** — Open Terminal
- **Ctrl + Shift + Esc** — System Monitor (varies)
- **Super** — Open application menu
