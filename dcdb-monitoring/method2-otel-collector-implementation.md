# Method 2 Implementation Plan: OTel Collector (Gateway OTLP + Postgres SQL)

## Overview

Follow the KubeDB postgres monitoring pattern with an **OTel Collector sidecar** that collects from both the Gateway (native OTLP) and Postgres (sqlquery receiver). One sidecar, one Service, one ServiceMonitor.

```
DocumentDB Pod
├── documentdb (main: Postgres :9712 + Gateway :10260)
│     ├── OTEL_METRICS_ENABLED=true         ← new env vars
│     └── OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4317
└── otel-collector sidecar
      ├── otlp receiver ← Gateway pushes to localhost:4317
      ├── sqlquery receiver → localhost:9712 (Postgres metrics)
      └── prometheus exporter → :8888/metrics

Service <db>-stats → port 8888
ServiceMonitor → Prometheus → Grafana
```

---

## What This Method Gives You (vs Method 1)

| Aspect | Method 1 (Dual Exporters) | Method 2 (OTel Collector) |
|--------|--------------------------|---------------------------|
| **Postgres metrics** | 494 standard PG metrics (postgres_exporter) | Custom SQL metrics (only what you define in YAML) |
| **Gateway metrics** | Only `mongodb_up` (limited) | **10 native OTLP metrics** (duration, ops, docs, startup) |
| **Sidecars** | 2 (postgres-exporter + mongo-exporter) | 1 (otel-collector) |
| **Config updates** | Requires operator code change | Add SQL in ConfigMap YAML, no code change |
| **Best for** | Standard Postgres monitoring | Custom metrics + full gateway visibility |

```go
var otelStaticConfig string

func (c *Reconciler) getOTelConfigMapName(db *dbapi.DocumentDB) string {
    return db.OffshootName() + "-otel-config"

func generateOTelDynamicConfig(db *dbapi.DocumentDB) map[string]string {
    port := 8888
    if db.Spec.Monitor != nil && db.Spec.Monitor.Prometheus != nil {
        port = int(db.Spec.Monitor.Prometheus.Exporter.Port)
    }

    otlpEndpoint := "http://localhost:4317"
    if db.Spec.Monitor != nil && db.Spec.Monitor.Prometheus != nil && db.Spec.Monitor.Prometheus.GatewayOTel != nil {
        if db.Spec.Monitor.Prometheus.GatewayOTel.OTLPEndpoint != "" {
            otlpEndpoint = db.Spec.Monitor.Prometheus.GatewayOTel.OTLPEndpoint
        }

        "static.yaml":  otelStaticConfig,
```

### Step 3: Embedded static OTel config

**New file:** `pkg/controllers/otel_static.yaml`

```yaml
receivers:
  otlp:
    protocols:
      grpc:
        endpoint: 127.0.0.1:4317
  sqlquery:
    driver: postgres
    datasource: "host=127.0.0.1 port=9712 user=${env:PGUSER} password=${env:PGPASSWORD} dbname=postgres sslmode=disable"
    queries:
      - sql: "SELECT 1 AS up"
        metrics:
          - metric_name: "documentdb.postgres.up"
            value_column: "up"
            data_type: gauge
      - sql: "SELECT count(*) AS total FROM pg_stat_activity"
        metrics:
          - metric_name: "documentdb.postgres.connections"
            value_column: "total"
            data_type: gauge
      - sql: "SELECT count(*) AS total FROM pg_locks"
        metrics:
          - metric_name: "documentdb.postgres.locks"
            value_column: "total"
            data_type: gauge
    collection_interval: 30s

processors:
  memory_limiter:
    check_interval: 1s
    limit_percentage: 80
    spike_limit_percentage: 25
  batch:
    send_batch_size: 1024
    timeout: 5s
```

### Step 4: OTel Collector sidecar — petset.go

```go
func (c *Reconciler) getOTelCollectorContainer(db *dbapi.DocumentDB) core.Container {
    port := 8888
    if db.Spec.Monitor != nil && db.Spec.Monitor.Prometheus != nil && db.Spec.Monitor.Prometheus.Exporter.Port != 0 {
        port = int(db.Spec.Monitor.Prometheus.Exporter.Port)
    }

    return core.Container{
        Name:  "otel-collector",
        Image: "ghcr.io/open-telemetry/opentelemetry-collector-releases/opentelemetry-collector-contrib:0.124.0",
        Args: []string{
            "--config=file:/etc/otel/static.yaml",
            "--config=file:/etc/otel/dynamic.yaml",
        },
        Env: []core.EnvVar{
            {
                Name: "POD_NAME",
                ValueFrom: &core.EnvVarSource{
                    FieldRef: &core.ObjectFieldSelector{FieldPath: "metadata.name"},
                },
            },
            {
                Name: "PGUSER",
                ValueFrom: &core.EnvVarSource{
                    SecretKeyRef: &core.SecretKeySelector{
                        LocalObjectReference: core.LocalObjectReference{Name: db.Spec.AdminAuthSecret.Name},
                        Key: "username",
                    },
                },
            },
            {
                Name: "PGPASSWORD",
                ValueFrom: &core.EnvVarSource{
                    SecretKeyRef: &core.SecretKeySelector{
                        LocalObjectReference: core.LocalObjectReference{Name: db.Spec.AdminAuthSecret.Name},
                        Key: "password",
                    },
                },
            },
        },
        Ports: []core.ContainerPort{{
            Name:          mona.PrometheusExporterPortName,
            ContainerPort: int32(port),
            Protocol:      core.ProtocolTCP,
        }},
        VolumeMounts: []core.VolumeMount{{
            Name:      "otel-config",
            MountPath: "/etc/otel",
            ReadOnly:  true,
        }},
        Resources: core.ResourceRequirements{
            Requests: core.ResourceList{
                core.ResourceCPU:    resource.MustParse("50m"),
                core.ResourceMemory: resource.MustParse("48Mi"),
            },
            Limits: core.ResourceList{
                core.ResourceCPU:    resource.MustParse("200m"),
                core.ResourceMemory: resource.MustParse("128Mi"),
            },
        },
    }
}
```

### Step 5: Gateway OTLP env vars — petset.go

Modify `getMainContainerEnvs()` to inject OTel env vars when monitoring is enabled:

```go
func (c *Reconciler) getMainContainerEnvs(db *dbapi.DocumentDB) []core.EnvVar {
    envs := []core.EnvVar{
        // ... existing env vars ...
    }

    // Enable gateway OTLP when monitoring with OTel collector
    if db.Spec.Monitor != nil && db.Spec.Monitor.Prometheus != nil && db.Spec.Monitor.Prometheus.GatewayOTel != nil {
        if db.Spec.Monitor.Prometheus.GatewayOTel.Enabled {
            endpoint := db.Spec.Monitor.Prometheus.GatewayOTel.OTLPEndpoint
            if endpoint == "" {
                endpoint = "http://127.0.0.1:4317"
            }
            envs = append(envs,
                core.EnvVar{Name: "OTEL_METRICS_ENABLED", Value: "true"},
                core.EnvVar{Name: "OTEL_EXPORTER_OTLP_ENDPOINT", Value: endpoint},
            )
        }
    }

    return envs
}
```

## What Metrics You Get

### From Gateway (OTLP push, 10 metrics):
```
db.client.operation.duration.total    — with Postgres phase breakdown
db.client.operations                   — operation count by type
db.client.request.size.total           — incoming payload bytes
db.client.response.size.total          — outgoing payload bytes
db.client.documents.returned           — find/aggregate/getmore
db.client.documents.inserted           — insert operations
db.client.documents.updated            — update/findAndModify
db.client.documents.deleted            — delete operations
gateway_startup_delay_ms               — startup time histogram
gateway.starts                         — restart counter
```

All labeled with: `db.system.name`, `db.operation.name`, `db.collection.name`, `db.namespace`, `error.type`

### From Postgres (sqlquery receiver, extensible):
Start with 3 baseline queries (up, connections, locks). Add more by editing `otel_static.yaml` — any SQL that returns a number becomes a metric.

### Comparison: OTel vs postgres_exporter for Postgres metrics

| | postgres_exporter (Method 1) | OTel sqlquery (Method 2) |
|---|---|---|
| Metrics out of the box | 494 | ~3 |
| Custom metrics | flags/config file | SQL in YAML |
| Best for | Comprehensive standard PG monitoring | Specific custom queries |

**Recommendation:** Use **both**. The OTel Collector for gateway OTLP + the postgres_exporter for comprehensive Postgres metrics. Or use the postgres_exporter sidecar alongside the OTel Collector sidecar for complete coverage.
