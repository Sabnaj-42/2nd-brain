# GRE Study Plan -- Quant-Heavy, Target 300+

Goal: **>= 300 combined (V+Q)**, ideally ~308-312 with **Quant 160+** and **Verbal ~148-152**.
This backs up the FAMU CIS application (waiver pending); a 160+ Quant also helps any future PhD path.

---

## Phases

### Phase 0 -- Diagnostic (Week 1)
- Take the **free ETS Mini Quiz** (10 Q) for a quick feel.
- Take **POWERPREP Online Test 1 (untimed)** as a real diagnostic -> note section scores.
- Skim the **ETS Math Review PDF**; list weak Quant topics (arithmetic / algebra / geometry / data analysis).
- Outcome: a baseline score + a prioritized weak-topic list.

### Phase 1 -- Foundation (Weeks 2-4)  *Quant focus*
- **Quant:** 1 ETS Math Review chapter/day + corresponding PrepSwift videos + 20-30 drill problems
  (Manhattan 5 lb.). Topics in order: Arithmetic -> Algebra -> Geometry -> Data Analysis.
- **Verbal:** start Magoosh free vocab app (50-100 words/day) + read the Verbal section overview here.
- **AW:** read `analytical_writing/issue_task.md`; write 1 untimed practice essay using the template.
- Weekly: 1 timed mini-section each of Verbal and Quant from official sources.

### Phase 2 -- Practice / Volume (Weeks 5-7)
- **Quant:** heavy drilling by question type (QC, MC, Numeric Entry, Data Interpretation). Target
  accuracy 80%+ on medium, then move to hard. Use PrepSwift "hard" sets + Manhattan 5 lb.
- **Verbal:** 1 RC passage + 1 TC set + 1 SE set daily; keep vocab daily.
- **AW:** 1 timed (30 min) essay per week.
- Weekly: re-take **POWERPREP Test 2 (timed)** and **buy 1 POWERPREP Plus** mock mid-phase to track score.

### Phase 3 -- Full Mocks & Refinement (Weeks 8-10)
- 1 full timed mock per week (POWERPREP Plus #2, #3).
- Review **every** wrong answer -- log the mistake type (careless / concept / strategy / timing).
- Time-box strategy: per-question target ~1.5 min Quant, ~1 min Verbal; mark-and-return on >2 min.
- Lighten new content; focus on weak-topic review + error log.

## Quant target breakdown (160+ means ~75-85% correct across both sections, weighted by difficulty)

Concept priorities (high ROI on the GRE):
1. **Number properties** (integers, primes, evens/odds, divisibility, positives/negatives).
2. **Fractions / decimals / percents / ratios** (show up constantly).
3. **Algebra** (linear & quadratic equations, exponents/roots, inequalities, functions/symbolism).
4. **Word problems** (rates/work, mixtures, interest, sets/venn, probability, counting).
5. **Geometry** (lines, angles, triangles, circles, coordinate geometry, mensuration).
6. **Data analysis** (mean/median/mode, SD, reading graphs/tables, basic probability).
