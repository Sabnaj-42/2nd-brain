# GRE Prep Hub

Everything I need to prepare for the **GRE General Test**, in one place. Built to back up the
**FAMU CIS MS Computer Science** application (GRE requirement: **>= 300 combined Verbal + Quantitative**,
or an approved waiver -- my waiver request to Cedrita Demus is pending, so I'm prepping as a backup).

---

## Key facts at a glance (verified on ETS, current "shorter GRE" since Sep 22, 2023)

| Item | Detail |
|---|---|
| Test length | ~1 hour 58 minutes, 5 sections |
| Sections | Analytical Writing (1 "Analyze an Issue", 30 min) / Verbal (2 sections) / Quant (2 sections) |
| Verbal timing | Sec 1: 12 q / 18 min / Sec 2: 15 q / 23 min |
| Quant timing | Sec 1: 12 q / 21 min / Sec 2: 15 q / 26 min |
| Adaptive design | Section-level adaptive (Sec 2 difficulty depends on Sec 1 performance) |
| Tools | On-screen calculator for Quant only; mark/review; move freely within a section |
| Scoring | Verbal 130-170 / Quant 130-170 (1-pt increments) / Analytical Writing 0-6 (0.5-pt) |
| Cost | **US$220** worldwide |
| Score validity | 5 years |
| Retake policy | Once every 21 days, up to 5x per rolling 12-month period |
| Score control | ScoreSelect(R) -- send only my best scores |

## How to use this folder

1. **test_format.md** -- understand the structure, timing, and adaptation before anything else.
2. **resources.md** -- the master link list (official ETS first, then reputable third-party).
3. **study_plan.md** -- the phased plan (diagnostic -> foundation -> practice -> full mocks).
4. **quant/, verbal/, analytical_writing/** -- concept overviews + authored demo questions
   with full solutions, organized by section.
5. Track progress in a simple checklist; re-take POWERPREP every ~2 weeks to measure.
